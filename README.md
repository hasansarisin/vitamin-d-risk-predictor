# NHANES Vitamin D Risk Web App

Research prototype trained on NHANES August 2021–August 2023.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Current held-out metrics
- AUC: 0.760
- Accuracy: 0.800
- Sensitivity @ 0.50: 0.225
- Specificity @ 0.50: 0.954
- Brier: 0.142

Research only. Not a diagnosis or treatment recommendation.
